# ЭНЭКА.Командировки

Приложение в Microsoft Teams: заявки на командировки и бронирование служебных автомобилей.
Три интерфейса — вкладка и бот в Teams, бот в Telegram для водителей — над одним сервером
и одной базой данных.

## Документация

| Файл | Что внутри |
|---|---|
| `docs/source/` | Исходные требования: концепция и состав этапа 1 (экраны Э1–Э9, карточки К1–К16, сообщения Т1–Т6) |
| `docs/plan.md` | Принятые решения, чек-лист доступов, порядок инкрементов и статус |
| `CLAUDE.md` | Стек, архитектура, правила кода, инварианты |

## Стек

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Supabase (Postgres) ·
botbuilder (Teams) · grammy (Telegram) · Zod

## Запуск

```bash
cp .env.example .env.local   # заполнить, см. docs/plan.md, раздел И0
npm install
npm run dev
```

Приложение открывается внутри Teams, а не в браузере: вкладке нужен токен от клиента
Teams. Публичный адрес даёт Vercel — там же живёт production-версия. Для локальной
работы над вкладкой нужен HTTPS: `npm run dev:https`.

## Размещение

| Что | Где |
|---|---|
| Приложение: вкладка и вебхуки ботов | Vercel, сборка из `main` |
| Воркер-планировщик и синхронизация сотрудников | VPS в Docker |
| База данных | Supabase |

## Команды

```bash
npm run dev             # dev-сервер
npm run dev:https       # dev-сервер по HTTPS — нужен для вкладки внутри Teams
npm run build           # production-сборка
npm run lint            # ESLint
npm run teams:package   # собрать манифест и иконки приложения Teams
```
